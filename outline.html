Unit Outline

COS10026

Web Technology Project

Aims

Students who successfully complete this unit can:

  1. UL01 Identify web technologies' core components and functions to establish a foundational understanding.
  2. UL02 Implement a project plan using project management strategies to organise, prioritise, and monitor tasks effectively in a web development context.
  3. UL03 Apply team frameworks, communicate and work effectively within teams using suitable verbal and technological methods.
  4. UL04 Utilise database query techniques to create, retrieve, update, and delete data according to specific project needs.
  5. UL05 Demonstrate the use of web development technologies to develop functional web applications, incorporating professional ethics, project management skills, and security practices.
  6. UL06 Explain fundamental security principles in web development and demonstrate their implementation in basic applications.
  7. UL07 Assess ethical considerations and security practices in web development, including accessibility and user privacy.

Content

  • Core Front-End and Back-End Development
  • Project-Based Learning and Version Control
  • Project Planning and Project Management
  • Web Security, Ethics, and Accessibility
  • Database Query Techniques
  • Professional Communication and Presentation
  • Teamwork Framework
